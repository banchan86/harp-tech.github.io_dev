## Overview

This is a registry for devices using the Harp Protocol.  To find out more about a specific device, visit the project url link or the author pages in the following section. To register a device, raise a PR on the [WhoAmI](https://github.com/harp-tech/whoami) repository. Registration is not compulsory, but highly recommended.
